# roman-core

Algarismos romanos 1..3999: codificação canônica, decodificação estrita,
ida-e-volta exaustiva garantida. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 6 testes com volta completa 1..3999, sem dependências
npm run demo
```

Somente forma subtrativa padrão. MIT — veja `LICENSE`.
